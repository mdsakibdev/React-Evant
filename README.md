# React Evant

A simple, modern, and interactive React application built to practice and demonstrate **React Event Handling**, State Management, and Component Structure.

## 🚀 Features

- ⚛️ **React State & Event Handling**: Clean demonstration of event listeners, state updates, and props passing.
- 🔢 **Counter & Interactive Components**: Features dynamic count addition, removal, and state controls.
- 🎨 **Modern UI & Responsive Design**: Simple, clean, and intuitive user interface.
- ⚡ **Fast & Lightweight**: Built with modern React tools for fast development and execution.

## 🛠️ Tech Stack

- **Frontend**: React.js, JavaScript (ES6+), HTML5, CSS3
- **Build Tool**: Vite / Create React App
